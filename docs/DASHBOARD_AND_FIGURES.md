# Dashboard and Figures Guide

This document explains how the Desc2Fix replication package generates static Plotly figures and provides an interactive Streamlit dashboard for exploring the human-evaluation results.

It complements:

```text
docs/HUMAN_EVALUATION.md
docs/REPRODUCTION_WORKFLOW.md
docs/RESULTS_GUIDE.md
```

---

## 1. Purpose

The visualization layer has two goals:

1. Generate paper-ready static figures in high-definition formats.
2. Provide an interactive dashboard for exploring RQ1/RQ2/RQ3/RQ4 results.

The visualization layer is based on Plotly and Streamlit.

```text
Plotly     -> static and interactive figures
Kaleido    -> high-resolution PNG/PDF/SVG export
Streamlit  -> multipage interactive dashboard
```

---

## 3. Static Plotly figures

### 3.1 Script

Static figures are generated with:

```text
scripts/generate_plotly_figures.py
```

Run:

```bash
python scripts/generate_plotly_figures.py
```

Optional:

```bash
python scripts/generate_plotly_figures.py \
  --tables-dir results/tables/human_evaluation \
  --output-dir results/figures/human_evaluation_plotly \
  --formats html png pdf \
  --scale 6
```

### 3.2 Output directory

The generated figures are stored in:

```text
results/figures/human_evaluation_plotly/
```

Each figure is exported as:

```text
.html  -> interactive browser version
.png   -> high-resolution raster figure
.pdf   -> LaTeX-ready vector/static figure
```

The default export scale is:

```text
scale = 6
```

This gives high-definition figures suitable for papers, slides, and README previews.

---

## 4. Dependencies

Install the visualization dependencies with:

```bash
python -m pip install plotly kaleido streamlit
```

If PNG/PDF export fails, Kaleido is usually missing or outdated:

```bash
python -m pip install -U kaleido
```

HTML export does not require Kaleido.

## 6. Figure style

The figures follow the same style as the paper-level Plotly scripts:

```text

large fonts
```

The goal is to keep the figures readable in:

```text
LaTeX papers

presentation slides
GitHub README
interactive browser views
```

## 9. Running the dashboard

Install Streamlit:

```bash
python -m pip install streamlit
```

Run from the repository root:

```bash
streamlit run dashboard/app.py
```

The dashboard expects the following directories to exist:

```text
results/tables/human_evaluation/
results/figures/human_evaluation_plotly/
```

If the tables are missing, run:

```bash
python scripts/generate_human_summary_tables.py --human-root Human_Eval
```

If the figures are missing, run:

```bash
python scripts/generate_plotly_figures.py
```

## 13. Troubleshooting

### 13.1 Streamlit is not installed

Error:

```text
ModuleNotFoundError: No module named 'streamlit'
```

Fix:

```bash
python -m pip install streamlit
```

### 13.2 Static image export fails

If `.html` files are generated but `.png` or `.pdf` export fails, install or update Kaleido:

```bash
python -m pip install -U kaleido
```

### 13.3 Dashboard cannot find tables

Regenerate tables:

```bash
python scripts/generate_human_summary_tables.py --human-root Human_Eval
```

Check:

```bash
ls results/tables/human_evaluation/
```

### 13.4 Dashboard cannot find figures

Regenerate figures:

```bash
python scripts/generate_plotly_figures.py
```

Check:

```bash
ls results/figures/human_evaluation_plotly/
```

### 13.5 Running from the wrong directory

The recommended command is from the repository root:

```bash
streamlit run dashboard/app.py
```

The dashboard also attempts to resolve paths when launched from the `dashboard/` directory, but launching from the repository root is preferred.
